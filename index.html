GATE 2027 Photo & Signature Resizer — Free JPG Tool

Short answer: upload a JPG, PNG or WebP, crop to the GATE 2027 frame, then export a JPG and check pixels, aspect ratio and file size before submitting. Photo: 200×260 to 530×690 px, ratio 0.66–0.89, 5–600 kB. Signature: 250×80 to 580×180 px, ratio 2.75–3.75, 3–300 kB. Processing runs locally in your browser — nothing is uploaded.

How it works

  1. Upload a clear photograph or signature.
  2. Crop and position with zoom and rotate.
  3. Check dimensions, ratio and file size, then download the JPG.

FAQs

Does the tool upload my image?

No. Processing happens in your browser using the native Canvas API.

Will passing the checks guarantee acceptance?

No. Pixels, ratio and file size are automatic; face position, glare and handwriting need visual review.

Which photograph does GATE 2027 accept?

A color passport-size JPEG/JPG, 200x260 to 530x690 pixels, ratio 0.66-0.89, 5-600 kB, plain white background, face covering 60-70% of the frame.

Which signature does GATE 2027 accept?

A JPG/JPEG of the full signature in black or dark-blue ink, 250x80 to 580x180 pixels, ratio 2.75-3.75, 3-300 kB, covering about 70-80% of the image.

Where do these requirements come from?

From the official GATE 2027 instructions published by IIT Madras for gate2027.iitm.ac.in.
